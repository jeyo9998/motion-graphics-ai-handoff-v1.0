# Project Context

## Project identity

**Motion Graphics AI Collaboration Framework**

An open-source framework intended to help multiple compatible AI-agent platforms understand, plan, execute, and evaluate Motion Graphics work.

## Vision

Make practical Motion Graphics knowledge and workflows reusable across AI agents and creative applications, so agents can participate in real work rather than only explain how work could be done.

## Initial application targets

- Alight Motion
- Adobe After Effects

They have equal initial priority. The goal is comparable ability to achieve a shared creative outcome, not identical interfaces, features, project formats, or technical procedures.

## Core capabilities sought

- Understand user intent, project context, requirements, constraints, dependencies, and acceptance criteria.
- Apply shared Motion Graphics and animation principles.
- Adapt shared creative intent to each application's verified capabilities and terminology.
- Actively collaborate and perform supported work when tools and permissions allow.
- Choose among direct file manipulation, scripting/API access, and application interaction.
- Evaluate outputs against observable criteria.
- Diagnose errors and record verified lessons.

## Non-goals and boundaries

- Do not make Alight Motion and After Effects technically identical.
- Do not promise every AI client can load or execute every Skill identically.
- A portable `SKILL.md` does not itself provide application access, automation, or permissions.
- Do not claim untested application integrations or file-format support.
- Do not replace the user's creative judgment or approval.
- Do not modify, overwrite, delete, export, or publish user work without appropriate authority.

## Important project philosophy

The framework is intended for active collaborators with bounded authority. Agents should take useful initiative—inspect accessible context, identify what is needed, propose plans, perform supported work, and evaluate results—while respecting user intent, tool limitations, and permission boundaries.

The guiding statement in the specification is:

> Build AI agents that understand the creative goal, adapt to the application, take useful initiative, perform work when tools allow, verify what they produce, and improve through evidence.
